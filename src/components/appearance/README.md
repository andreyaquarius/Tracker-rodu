# Personal application appearance

The Settings page and profile menu share `AppAppearanceSettings`: Standard (existing default) or Dark with a starry sky, plus an independent motion switch. Available to viewers as well as project owners.

- `AppAppearanceProvider` wraps the router once, including standalone pages and dialogs. It changes root CSS tokens without replacing pages, clearing editors, navigating, or saving project data.
- `useAppAppearanceAccount` receives the ID from the existing authenticated app flow. The `tracker-rodu:appearance:v1:account:<id>` cache is personal to an account **and browser**, with a separate guest preference. It is not cross-device sync. Other browser tabs receive storage events. Blocked storage preserves the current session and displays a warning. There is no migration or backend change.
- `--app-ink`, `--app-ink-muted`, status colors, surfaces and borders are semantic night-only tokens. Existing CSS declarations retain original light values as fallbacks. Do not change the dark brand-green variables to white: they also supply filled button backgrounds. Theme text and background separately. Keep images, scans, map tiles, and logos unfiltered.
- `StarrySkyCanvas` is shared by the app, classic/direct-pedigree trees, and the constellation. Star radius/speed use actual CSS pixels; width/height are viewport dimensions, never diagram bounds or camera zoom. It has 45–220 stars, a 3MP backing-buffer ceiling, cached glows/nebulae, and at most one occasional comet. No remote assets or frame-by-frame React/graph work.
- Animation respects user pause, reduced-motion and visibility; unmount cancels the loop and resize observer. Global pause also pauses skies inside diagrams. Tree-specific pause is retained. The global dark theme enables night tree palettes without changing stored tree preferences; returning to Standard restores the original per-tree choice. Circular/fan charts retain their static-export-capable SVG sky.
- Root tokens also theme portal dialogs and lazy-loaded modules. Print hides the global decorative canvas and resets night tokens. Diagram-specific exports retain their own selected appearance.

Validation: `test/appAppearance.test.ts`, tree/constellation suites and local Playwright fixtures in `.tmp/app-theme-qa` / `.tmp/starry-tree-qa` (synthetic data, no production writes). Cover theme restoration, account changes/logout, storage events and failures, open drafts, keyboard labels, 320/390px layouts, SVG labels, contrast, reduced motion, animation pause, unchanged tree layout/camera and export.
