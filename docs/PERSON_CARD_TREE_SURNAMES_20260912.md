# Однакове відображення жіночих прізвищ у дереві й картці

## Поведінка

- Список і плитки каталогу, повна картка особи (заголовок і поле «Відображуване ім’я») та короткий перегляд успадковують налаштування відповідного дерева: дівоче, шлюбне або обидва прізвища у вибраному порядку. Ініціали також відповідають видимому прізвищу.
- Використовується той самий форматувальник, що й у дереві. Він враховує структуровані імена типу `birth` / `maiden` / `married`, звичайне поле дівочого прізвища та необов’язкове використання прізвища чоловіка.
- Контекст — вибране дерево; для прямого переходу в профіль без вибраного дерева використовується вже завантажене стандартне дерево проєкту.
- Читання налаштувань у картці не створює й не перезаписує серверні налаштування. Зміни браузерного кешу підхоплюються у поточній та інших вкладках.
- Записи осіб, редактор, написання з джерел і експорт не перезаписуються. Явний режим «Оригінальне написання» залишається дослівним. Чоловічі імена та картки без контексту дерева зберігають попередню поведінку.
- Для відсутнього другого прізвища показується відоме; однакові прізвища не дублюються в дужках. Збережено по батькові для старих записів, де воно є лише в повному імені.
- Каталог сортується за видимим іменем; порядок «Від центральної особи» зберігає родинні ранги. Пошук знаходить обидва прізвища, зокрема записані лише у `person_names` (якщо для варіанта дозволено пошук). Дії рядка, вибір і експорт отримують незмінений оригінальний `Person`.
- Для каталогу поля імен читаються посторінково по 500 у межах проєкту, із RLS та скасуванням запиту при виході/зміні контексту. Немає запиту на кожний рядок або при кожному натисканні клавіші. Біографії, документи й тексти приміток до імен для цього не завантажуються. Це окрема проєкція, не джерело для резервної копії/редактора.
